# 架构与数据模型

静态 HTML/CSS/ES 模块，浏览器原生 API；无数据库服务器与密钥。选择静态实现避免本机依赖安装与静态托管不兼容，仍保留数据与视图分离。

- courses: 稳定课程 ID、先修、PDF 文件/页码/节点、规则与例句、常错、文章和练习。
- article: 稳定 ID、CEFR、正文/译文、目标句、词汇、理解与迁移。
- exercise: 稳定 ID、题型、CEFR、答案列表、重音敏感性、解析与误区。
- exam: 官方事实来源、各任务要求、按任务与主题分类的原创口语/写作题，以及分级范例。
- 浏览器持久化: 课程完成、自评、作答记录、错题、收藏、口语日志、写作草稿与历史；导入带版本验证。

CEFR 是内容难度标签，不是学习者成绩；不把它等同于 NCLC。未提供未经核实的成绩映射。不存在模拟 AI 结果。

路由使用 hash，不要求静态主机服务端重写。课程树、文章、练习共享结构数据；所有用户输入需 HTML 转义。导入 JSON 只读数据、不执行内容。服务工作线程只管理同源静态资源，更新时删除本应用旧缓存。

## 后续接口

账号、云同步、AI 反馈与语音分析需要单独安全后端；须实现用户授权、隐私说明、错误处理和费用管理。前端中不得保存服务密钥。新增服务之前重新确定范围与成本。
